# Brain

Working notes for Hyper live in five folders. A file records a rule or a result that was actually computed. A missing reading stays missing.

| Folder | What it holds | File name |
| --- | --- | --- |
| `Memory` | Durable facts and choices that stay in force | `Memory – Thema.md` |
| `Abläufe` | Repeatable procedures | `Ablauf – Aufgabe.md` |
| `Skills` | How a reading is made | `Skill – Thema.md` |
| `Arbeiten` | Open work, including the open idea | `Arbeit – Thema.md` |
| `Ergebnisse` | Outputs, including the last spoken script | `Ergebnis – Thema.md` |

The en dash in the file name separates the kind from the topic. Example: `Skill – Trendfilter.md`.

Paper only. Nothing in this folder places an order.
